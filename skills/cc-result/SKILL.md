# Claude Code job result

Resolve the plugin root as two directories above this `SKILL.md`. Run `node <plugin-root>/scripts/cc-companion.mjs result` with the requested job ID, or without one for the latest finished or waiting job. Preserve the full Claude result and cost-estimate label.
